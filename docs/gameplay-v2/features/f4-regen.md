## 現況

- `HealthComponent.hpRegen` 只來自裝備（+2、+10/秒），由 Host 在 `ECSPlayerManager` 每幀回血。
- 沒有基礎回血、脫戰回血與泉水。

## 需求

由 Host 計算，結果隨 GAME_STATE 的 hp 同步。

1. **基礎回血**：與裝備 `hpRegen` 相加。
2. **脫戰回血**：一段時間內沒受到傷害、也沒造成傷害時加速回血；受傷或出手立即中斷並重新計時。
3. **泉水**：位於自家主堡附近時快速回血；敵方泉水無效。
4. 回血時頭上顯示小幅綠色效果，與傷害數字區隔；脫戰回血開始時有提示。
5. 死亡時不回血；回血不超過最大生命。
6. Host 遷移時新 Host 從頭計算脫戰時間（可接受）。

## 驗收

- [x] 受傷後 5 秒不交戰，回血速度明顯加快；被打一下立即回到基礎速度（單元測試；2026-11-10 雙分頁實測每秒 2 → 5 秒後每秒 17 → 被打後回到每秒 2，出手的一方也重新計時）。
- [x] 站在自家泉水約 7 秒內回滿；站在敵方泉水不回血。（實測 100 → 1000 約 6 秒；敵方泉水每秒只有基礎 2）
- [x] 死亡狀態不回血；回血不超過最大生命。（實測陣亡 5 秒血量維持 0，重生回滿且不跳回血數字）
- [x] Client 看到的血量與 Host 一致。（相隔 0.46 秒讀取兩端，差距等於這段時間的回血量）
