## 現況

- 命中判定由 `CollisionSystem.checkHitboxCollisions` 以 Rapier `intersectionPair` 比對技能判定球與單位碰撞體，等於「邊緣到邊緣」計算，受擊框大小直接影響命中。
- 英雄與小兵的碰撞體都是 `cuboid(0.3, 0.5, 0.3)`（`src/core/ecs/EntityFactory.ts`），會隨面向旋轉。
- 實測外觀（像素圖不透明區域 ÷ 每單位 19 像素）：英雄戰鬥姿態寬約 1.6、高約 1.8；小兵寬約 1.1。受擊框只有外觀寬度的 37%～55%。
- 火球命中用中心距離 `HIT_DISTANCE = 0.8 + 0.5`（`src/core/combat/ProjectileManager.ts`），不看目標體型。

## 需求

1. 每個單位分成兩種大小：
   - **受擊範圍**：決定技能是否命中；圓柱、不隨面向旋轉，約為外觀寬度的 80%。
   - **移動佔位**：決定移動時是否被地形擋住（F5 才使用），比受擊範圍小，避免轉角卡住。
2. 英雄、小兵的受擊範圍改為圓柱，數值見 balance.md；塔、主堡不變。
3. 投射物以「投射物半徑 + 目標受擊半徑」判斷命中。
4. 實作上受擊範圍可用獨立的感測碰撞體（sensor），與移動用的碰撞體分開。

## 驗收

- [ ] 英雄和小兵的受擊範圍是圓柱，旋轉角色後同一位置的命中結果不變（單元測試）。
- [ ] 火球擦過敵人外觀邊緣時會命中。
- [ ] 除錯顯示（F3）畫出的受擊圈與角色外觀大致吻合（截圖確認）。
