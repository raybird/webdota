## 現況

- `src/data/maps/demo_arena.json`：60×60（四周牆在 ±28，可走 56×56），中央與四角有柱子、四個木箱，每隊 2 塔 1 主堡（主堡 5000 HP）。
- 小兵從出生點直線走向敵方主堡（`ECSCreepManager`），沒有路線。
- `MovementSystem.moveEntity` 直接設定 kinematic 位置，沒有地形碰撞，也沒有地圖邊界限制；`MapManager.getMapBounds()` 沒有被呼叫。
- 小地圖大小在 `GameView.vue` 寫死為 60×60。

## 需求

1. 新地圖 `arena_v2`，約 96×96；`demo_arena` 保留作為測試圖。
2. 佈局：主堡在對角，一條斜向主路，兩側為野區，以牆或障礙物隔出入口；草叢沿主路兩側與野區內分布（規則見 F7）。
3. 每隊 3 座塔：外塔、內塔、主堡前塔。**依序攻擊**（決策 D15）：前一座未破時，後面的建築無敵並有提示。
4. 小兵沿**中繼點**走主路；遇到敵方單位照現有 AI 交戰。
5. **移動碰撞**：英雄與小兵以移動佔位（F2）與地形碰撞，不能穿牆、柱子、建築，也不能走出地圖；貼牆時沿牆滑動。單位之間先不互相阻擋。
6. Host 權威、Client 用同一套碰撞預測，差距大時沿用現有拉回機制。
7. 小地圖大小改讀地圖設定。
8. 地圖草圖放在 `docs/gameplay-v2/maps/`，確認後才實作。

## 驗收

- [x] 角色無法穿過牆、柱子、建築，也無法走出地圖；貼牆移動會沿牆滑動、不會卡住。單元測試涵蓋穿牆、斜撞滑動、長距離位移、圓柱繞行、地圖邊界；瀏覽器實測撞主堡停在 z = −35.1、撞外牆停在 x = −45.6，走不進封閉區。
- [x] 小兵沿主路走到敵方塔與主堡，不會卡在障礙物。瀏覽器實測 25 秒內兩隊小兵沿對角線前進，在中央柱附近相遇後停下交戰。
- [x] 外塔未破時打不動內塔，並有提示。受保護的建築血條變灰，本地玩家走近時建築上方顯示「先摧毀前一座塔」；Host 與 Client 的保護狀態相同。
- [x] 主堡到主堡步行約 20～25 秒（直線約 21.5 秒；測試沿主路走到敵方主堡前 17～22 秒）。
- [x] 小地圖正確顯示新地圖全貌與單位位置（大小讀地圖設定，畫出牆、柱子與封閉區）。
- [x] 844×390、640×360、1280×720 截圖確認鏡頭、HUD 與地圖比例正常。
