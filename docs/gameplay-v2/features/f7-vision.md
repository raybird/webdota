## 改版前（2026-11-10）

- 全圖互相可見，小地圖顯示所有單位。
- Host 廣播所有單位的狀態給每個人。

## 需求

只在畫面上處理，所有狀態照常同步（決策 D3）。

1. **視野**：每個友方單位有視野半徑，隊伍視野為聯集；以格子計算、定期更新。
2. **視野外**：
   - 地形變暗。
   - 敵方英雄與小兵的模型、血條、名字、狀態效果、小地圖點、傷害數字都隱藏。
   - 建築永遠可見（位置固定）。
   - 敵方的投射物與技能特效經過我方視野時照常顯示。
3. **草叢**：
   - 草叢內的單位，只有同一叢草內有敵方單位時才會被看到。
   - 在草叢內出手攻擊會暴露自己一小段時間。
   - 草叢不影響移動與技能判定。
4. 視野計算放在獨立模組，可做單元測試。

## 實作重點

- **計算**：`src/core/vision/vision.ts`（`VisionGrid` 格子視野、`BrushMap` 草叢、`isUnitVisible` 判斷），沒有 PlayCanvas 依賴。數值在 `src/data/balance.ts` 的 `VISION`。
- **套用**：`src/core/vision/FogOfWar.ts`，每一端依本地隊伍每 0.1 秒重算。視野來源是存活的我方英雄（9）、小兵（6）、塔（10）、主堡（12）。看不到的敵方英雄與小兵用 `RenderComponent.setFogHidden` 隱藏模型與血條；`GameEngine.isEntityVisible` 給小地圖、傷害數字（`DamageNumberLayer`）、受擊／死亡／重生／升級特效判斷。
- **地面變暗**：地面網格每 2 單位一個格點，`FogOfWar` 算出每個格點的亮度交給 `PixelMapSkin.setGroundShade` 當頂點色，約 0.25 秒淡入淡出（D27）。
- **草叢**：`PixelMapSkin.createBrush` 畫成高 1.25 單位的草堆（頂面 + 帶葉尖的正面，素材 `public/env/brush-*.png`）。本地英雄所在的草叢變半透明，我方躲在草叢裡的單位半透明，表示敵人看不到（D29）。
- **暴露**：每一端在 `applySkill` 成功施放後呼叫 `fog.reveal`，在草叢內的話 1 秒內看得到（D30）。
- **跟著單位的特效**：`SpriteFxManager` 的 `visible` 選項每幀判斷，例如「鋼鐵意志」的護盾在施法者進入迷霧或隱身時一起隱藏。

## 已知限制

- 牆、柱、草叢、建築在迷霧裡不會變暗，只有地面變暗（D27）。
- 投射物與技能特效（跟著單位的除外）不隱藏，在迷霧裡出手的特效看得到（D28）。
- 小兵在草叢內攻擊不會暴露（D30）。
- `?debug` 的受擊範圍圈會畫出所有單位，包括看不到的敵人（除錯用）。
