## 現況

- 全圖互相可見，小地圖顯示所有單位。
- Host 廣播所有單位的狀態給每個人。

## 需求

只在畫面上處理，所有狀態照常同步（決策 D3）。

1. **視野**：每個友方單位有視野半徑，隊伍視野為聯集；以格子計算、定期更新。
2. **視野外**：
   - 地形變暗。
   - 敵方英雄與小兵的模型、血條、名字、狀態效果、小地圖點、傷害數字都隱藏。
   - 建築永遠可見（位置固定）。
   - 敵方的投射物與技能特效經過我方視野時照常顯示。
3. **草叢**：
   - 草叢內的單位，只有同一叢草內有敵方單位時才會被看到。
   - 在草叢內出手攻擊會暴露自己一小段時間。
   - 草叢不影響移動與技能判定。
4. 視野計算放在獨立模組，可做單元測試。

## 驗收

- [ ] 視野計算（半徑、聯集、草叢規則）有單元測試。
- [ ] 敵人離開視野後在畫面與小地圖上消失，回到視野內重新出現。
- [ ] 躲在草叢內不被看到；進入同一叢草就看得到；草叢內攻擊會暴露。
- [ ] 視野更新不造成明顯掉幀（手機模擬下 FPS 不低於改版前 90%）。
