# F1 操作與按鍵提示

| 項目 | 內容 |
|---|---|
| 里程碑 | M1 操作與命中 |
| 狀態 | 未開始 |
| 相關決策 | D8、D9 |

## 現況

- WASD 與方向鍵依畫面方向移動，送出前用 `screenToWorld` 換算成世界方向（`src/core/view.ts`），紅藍兩隊鏡頭不同也一致。
- `src/core/managers/InputManager.ts`：`Q` 或 `1` 放技能 1，`2`～`4` 放技能 2～4，空白鍵或 `0` 普攻，另有 numpad 舊綁定。
- `src/components/SkillPanel.vue` 的提示寫 `Q / 1`、`W / 2`、`E / 3`、`R / 4`、`Space / 0`；W 實際是移動，E、R 沒有作用；手機也顯示提示。

## 需求

1. 桌機技能鍵：`1`～`4` 放技能 1～4，空白鍵放普攻；移除 `Q` 與 numpad 的技能綁定。
2. 桌機技能按鈕提示改為 `1`、`2`、`3`、`4`、`Space`。
3. 觸控裝置（`(hover: none) and (pointer: coarse)`）不顯示按鍵提示，其他版面不變。
4. WASD 與方向鍵移動維持現狀。

## 驗收

- [ ] 桌機按 `1`～`4`、空白鍵分別放出對應技能；按 `Q`、`E`、`R` 不會放技能。
- [ ] 桌機技能按鈕顯示數字鍵提示；手機模擬（844×390 觸控）不顯示任何按鍵提示。
- [ ] 在輸入框打字（例如大廳暱稱）不會觸發技能。
