# F3 技能範圍、面向箭頭與除錯顯示

| 項目 | 內容 |
|---|---|
| 里程碑 | M1 操作與命中 |
| 狀態 | 完成 |
| 相關決策 | D8、D10 |
| 數值 | [balance.md](../balance.md#技能範圍f3) |

## 現況

- `src/core/combat/ECSSkillExecutor.ts` 的立即判定把圓心放在施法者**前方 1 單位**，半徑為 `aoe`，沒有 `aoe` 時為 `range × 0.75`。
- 「震地猛擊」「冰霜新星」「旋風斬」「幻影殺陣」的說明是打周圍，實際上身後的敵人很容易打不到。
- 技能往角色面向方向放出，畫面上沒有方向提示。

## 需求

1. 技能新增判定中心設定：`front`（前方，預設）或 `self`（以施法者為中心）；打周圍的四個技能改用 `self`。
2. 技能範圍依 balance.md 調整（約放大 1.2 倍），技能說明文字同步更新數字。傷害與冷卻不動。
3. **面向箭頭**：腳下顯示技能會放出的方向；手機與桌機都顯示，只顯示給自己。
4. **除錯顯示**：按 `` ` `` 鍵（或網址加 `?debug`）在地上畫出各單位的受擊範圍與技能判定圈；預設關閉。

## 驗收

- [x] 四個 `self` 技能能打到身後的敵人（單元測試；實機輪詢確認震地猛擊判定圓心在角色身上、半徑 3.6）。
- [x] 面向箭頭隨移動方向轉動，放技能的方向與箭頭一致。（截圖確認往右走時箭頭朝右）
- [x] 除錯顯示開關正常，預設不顯示。（與既有除錯面板共用 `?debug` 與 `` ` `` 鍵）
- [x] 兩個分頁對打，實際命中與畫面一致（2026-11-10 Chrome 雙分頁：震地猛擊打到身後 4.0 的法師並往外推，兩端血量一致）。已知問題：Client 自己的英雄被擊退 2 以內時畫面不跟著動，見下方實作紀錄
