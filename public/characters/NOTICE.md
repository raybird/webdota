# webdota 原創角色像素素材

設計、產製與檢視日期：2026-11-06。

戰士、刺客與法師的角色設計、立繪、頭像及產生程式均為 webdota 原創，沒有模仿現有遊戲角色，沒有使用第三方角色素材或生成式圖片。
所有形狀直接繪於原始像素網格；不使用抗鋸齒、半透明、羽化、縮小量化或背景陰影。光源位於左上，外框採 `#1a1422`。
每個角色的立繪與頭像合計最多使用 16 種不透明顏色；透明像素不計。

## 重製方式（2026-11-06）

需求：Python 3 與 Pillow。2026-11-06 的產製環境使用 Python 3 與 Pillow 12.2.0，執行不需要網路。
從 repo 根目錄執行：

```sh
python3 tools/portraits/generate.py
```

此指令重製全部六張角色 PNG、三份 JSON、五張預覽 PNG 與 `tools/portraits/validation.json`。
相同版本 Pillow 的輸出可重現，程式不使用亂數、外部字型或外部素材。
若戰場連續圖已存在，原指令也會驗證其規格並保留戰場檢查結果。

三位角色四組動作合計分別使用 14、13、13 種不透明顏色，每張戰場 PNG 均小於 50000 bytes。

從 repo 根目錄離線重製戰場素材：

```sh
python3 tools/portraits/generate_battle.py
```

此指令重製 12 張戰場 PNG、12 份 JSON、兩張戰場預覽與 `tools/portraits/validation.json`，不寫入大廳 `<id>-idle.*` 或 `<id>-avatar.png`。
Python 3 + Pillow、固定整數像素、無亂數與網路依賴；共用既有配色及繪圖工具，場景素材僅唯讀取用。
`preview-battle.png` 逐列呈現三人四動作的全部 60 格，nearest-neighbor 放大 4 倍。
`preview-battle-scene.png` 使用 `ground-blue.png` 原生區域 [300,270,780,510]，各角色選取待機第 1 格、跑步第 3 格、攻擊第 3 格與施法第 3 格，與 v2 藍紅小兵、藍塔及小柱按原生比例及接地深度合成，再 nearest 放大 3 倍。
`validation.json` 的 `battle` 區塊記錄鏡頭、光源、無地面陰影設計、逐動作尺寸與播放契約、總高度、腳底、二值 alpha、獨立影格數、色盤及檔案大小；`scene` 記錄合成來源、來源 SHA-256 及 nearest 像素檢核區，`files` 記錄交付檔案 SHA-256。
施法收勢允許與起始姿勢相同，其餘動作每格皆有差異。
2026-11-06 已目視檢查全部 60 格與場景合成：三人設計可辨識、頂面及身高與小兵／塔／柱的斜俯視一致，左上光源一致，揮擊與施法清楚，無裁斷或烘焙地面陰影。
2026-11-06 重複執行戰場生成器，全部產物 SHA-256 相同；九份大廳 `<id>-idle.*` 與 `<id>-avatar.png`、`public/env/` 及 `public/fx/` 均與產製前逐位元組一致，產生器不寫入 `src/`。

## pixelfx 相容性與來源（2026-11-06）

像素語言與既有 `public/fx/` 一致，沿用其 `#1a1422` 外框色及 Aseprite 風格 metadata 契約，包括 `frames[].frame`、`meta.size`、`meta.image` 與 `meta.pixelfx` 欄位。
角色形狀、繪圖工具、動作與頭像皆自行撰寫，沒有複製或沿用 pixelfx 的角色骨架或程式碼。
